Access the System

Quick Start
  1. Go to /admin/dues in your app
  2. Login with admin or employee credentials
  3. View dashboard summary (4 cards)
  4. Find customer in the list and click "Collect"
  5. Fill collection form and generate receipt

Workflow Steps

1

Customer walks in

Employee checks dashboard → Finds customer → Views outstanding dues

2

Collect payment

Employee enters collection amount → Selects payment method → Records note (optional)

3

Generate receipt

Automatic receipt number → Khalil Computer branded header → Print/PDF options

4

Update records

Audit trail recorded → Dashboard updates in real-time → Customer due reduced

API Endpoints

Method Endpoint Purpose Role Access
GET /api/admin/dues/dashboard Dashboard summary (4 cards) Admin/Employee
GET /api/admin/dues/customers Customers with outstanding dues Admin/Employee
GET /api/admin/dues/customers/[phone] Customer detail by phone Admin/Employee
POST /api/admin/dues/collect Record due collection Admin/Employee
GET /api/admin/dues/history Collection history Admin Only
